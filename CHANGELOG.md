# Changelog

Every released version gets a `## [x.y.z] - YYYY-MM-DD` section here, newest
first. The release workflow pastes that section into the GitHub release notes
verbatim, so write it for someone installing the plugin, not for someone reading
the diff. `npm run check-changelog` fails if the section for `manifest.json`'s
version is missing or empty.

Entries are bilingual: Chinese, then `<br>`, then English, both on one source
line. The `<br>` is deliberate — a plain newline renders as a line break in
release notes but collapses to a space when this file is viewed on GitHub, and
the entry has to read correctly in both.

## [2.0.2] - 2026-09-18

笔记里嵌入的图片现在**直接画在卡片上**，点一下还能盖在导图上放大预览，视频也能在卡片上播；另外修好了就地编辑的三处手感：输入法的回车不再误关编辑框，注解条里 `Enter` 用来换行、代码块里 `Shift`+`Enter` 用来另起一行，`Tab` 也不会再把焦点扔到别处。<br>An embedded picture is **drawn on the card** now and opens enlarged over the map when clicked, and a video plays in place; plus three fixes to how in-place editing feels: an input method's Enter no longer closes the field, `Enter` writes a line in an annotation and `Shift`+`Enter` starts one in a code block, and `Tab` no longer throws the focus somewhere else.

### 新增 / Added

- **按住 `Space` 拖鼠标，可以在任何地方平移画布。** 以前只有空白处的拖拽是平移，指针一落在卡片上就变成拖动卡片或者选中卡片里的文字 —— 而想看一眼被挡住的角落时，卡片恰恰就在那儿。现在按住 `Space`，指针变成手形，左键从哪里按下去都拖动画布：卡片上、代码块里、表格上都一样，压在文字上也不会变成选中文字。按住期间鼠标整块归画布，所以点卡片也不会顺带把它选中。<br>**Hold `Space` and drag to pan the canvas from anywhere.** Only blank space used to pan: the moment the pointer crossed a card it became a card drag, or a drag-select of that card's text — and a card is exactly what is in the way when you want to see what is behind it. With `Space` held the pointer turns into a hand and a left press pans from wherever it lands: over a card, inside a code sample, across a table, without selecting a word of it. While the key is down the mouse belongs to the canvas, so a click does not select a card on the way past.
- **图片画在卡片上。** `![[hero.png]]` 和 `![hero](hero.png)` 不再是带文件名的斜体标签，而是图片本身。按它自己的尺寸画、绝不放大；宽度受**卡片最大宽度**限制，高度受新增的**媒体最大高度**限制（默认 200 像素）。`![[hero.png|120]]` 里的数字是宽度上限，`![[hero.png|色带]]` 里的竖线后面是别名。只有笔记库里的文件会被画出来 —— `![](https://…)` 这类远程地址保持标签，导图不会替你联网。<br>**Pictures are drawn on the card.** `![[hero.png]]` and `![hero](hero.png)` are the picture itself rather than an italic chip carrying its name. Drawn at its own size and never enlarged; its width is capped by **Maximum card width** and its height by the new **Maximum media height** (200 pixels by default). The number in `![[hero.png|120]]` is a width cap, and a name after the pipe in `![[hero.png|The bands]]` is an alias. Only files in the vault are drawn — a remote address such as `![](https://…)` stays a chip, because the map never goes to the network on your behalf.
- **视频卡片是一张首帧静止画面**，鼠标移上去才出现两个圆钮：**▶**（右下角）就地播放，卡片变成带进度条、音量和全屏的播放器；**⧉**（右上角）用 Obsidian 自己的播放器打开这个文件。开始播放后卡片不再是链接，点画面是暂停而不是打开文件。<br>A **video card is a still frame** with two circles, shown while the pointer is over it: **▶** (bottom right) plays it in place, turning the card into a player with a scrubber, volume and full screen, and **⧉** (top right) opens the file in Obsidian's own player. Once it is playing the card is no longer a link — clicking the picture pauses it rather than opening the file.
- **导出文件自带图片。** 导出的 SVG / PNG / HTML 里，图片会内嵌成 data URI，所以拷到别的机器、用浏览器打开都能看到 —— 以前那里是空白。视频不内嵌（体积太大），导出时退回成文字标签。<br>**An exported file carries its pictures.** In an exported SVG, PNG or HTML the pictures are inlined as data URIs, so the file shows them anywhere, on any machine — where they used to be blank. Videos are not inlined, because a minute of video is far too much to put in an HTML file; a video falls back to a text chip.
- **两个新设置**：**显示图片和视频**（默认开）和**媒体最大高度**（80–480，默认 200）。关掉前者，所有嵌入回到原来的标签形态。<br>**Two new settings**: **Show pictures and videos** (on by default) and **Maximum media height** (80–480, 200 by default). Turn the first one off and every embed goes back to the chip it was.
- **点一下就放大预览。** 点图片或视频，它会**盖在导图上放大显示**，背景变暗；点暗处、按 `Esc`、或点右上角的 ✕ 关掉。**不跳标签页，也不离开你正在看的这张图** —— 要打开文件本身，按住 `Ctrl`/`Cmd` 再点（视频另有右上角的 `⧉`）。预览最多放大到自身尺寸的 2 倍，再大只是把像素拉糊。<br>**Click a picture or a video to enlarge it.** It **covers the map**, the backdrop goes dark, and clicking that backdrop, pressing `Esc` or using the ✕ in the corner puts everything back. **No new tab, and no losing your place in the map** — to open the file itself instead, hold `Ctrl`/`Cmd` while you click (a video also has `⧉` in its top right). A preview enlarges up to twice the media's own size; past that it only stretches pixels.
- **正文块卡片可以折起来了** —— 段落、代码块、表格都行，不再只有代码块。卡片侧面多了和父节点一样的折叠按钮，点一下整块只剩第一行内容（代码块留下的正好是围栏那行，写着语言；段落留下的是第一句），按钮留在原处等着把整块展开；再点一下展开。只有一行的块没有这个按钮：折起来还是那一行，等于没折。按钮一直都在，状态和折叠父节点一样按笔记记住，从不写进你的 markdown。<br>**Any content card can be folded** — paragraphs, code and tables alike, not just code blocks. The card carries the same fold button a parent card does: press it and the block is down to its first line of content (for a sample the opening fence, which names the language; for a paragraph its first sentence) and the button stays out in the open, where a folded branch shows its count, waiting to open the whole block again. A block of one line has no button, because folding it would still be showing that line. The button never goes away, and the fold is remembered per note exactly as a branch's is — never written into your markdown.
- **代码块右上角多了语言角标和复制按钮。** 围栏声明的语言写在卡片右上角，鼠标移上去（或键盘聚焦时）多出一个复制按钮，点一下整段代码进剪贴板，成功时变成 ✓；两者都绝对定位在代码上方，既不改变卡片尺寸，也不会被当成代码的一部分。导出的文件里不带这个按钮（它就是给界面用的），语言角标留着。<br>**A sample's corner carries its language and a copy button.** The language the fence named sits in the top right of the card, and a copy button arrives under the pointer (or on keyboard focus) which puts the whole sample on the clipboard and turns into a ✓ while it does; both are absolutely positioned above the code, so neither changes the card's size and neither reads as part of the sample. An exported file does not carry the button — it is there for the interface — and keeps the language.
- **导图里能查找替换了。** `Ctrl`/`Cmd`+`H` 打开查找栏并直接展开替换行（`Ctrl`/`Cmd`+`F` 仍然只查找）。两个按钮是**只替换这张卡片**和**全部替换**，在替换框里按 `Enter` 就是全部替换。替换改的是笔记里的**原文**，所以 `**加粗**` 里的字被替换时，星号原地不动；一次替换不论动了多少张卡片，都只算**一步撤销**。<br>**Find and replace, on the map.** `Ctrl`/`Cmd`+`H` opens the find bar with its replace row already showing (`Ctrl`/`Cmd`+`F` still only finds). The two buttons are **Replace in this card** and **Replace all**, and `Enter` in the replace field is Replace all. A replacement writes into the note's **source**, so replacing a word inside `**bold**` leaves the asterisks where they were; and however many cards one replacement touches, it is **one undo step**.
- **一次可以选中好几张卡片。** 按住 `Shift`（或 `Ctrl`/`Cmd`）点卡片就把它加进选中，再点一次退出；在空白处按住 `Shift` 拖拽会拉出一个框，框住几张就选中几张。多选时 `Delete` 一次删掉全部，`Space` 一次折叠或展开全部 —— 都是**一步撤销**。框选和加选只动内存里的选中状态，笔记一个字都不改。<br>**Several cards can be selected at once.** Hold `Shift` (or `Ctrl`/`Cmd`) and click a card to add it, click it again to drop it; hold `Shift` on blank canvas and drag to sweep a box, and every card it covers is selected. With more than one selected, `Delete` removes them all and `Space` folds or opens them all — each as **one undo step**. Banding and adding only move the selection in memory; the note is not touched.
- **`> [!note]` 这样的 callout 现在画成卡片。** 图标、标题、正文各就各位，颜色按类型区分，和 Obsidian 阅读视图里看到的是同一套；笔记没写标题时用 Obsidian 内置的那个标题（跟随界面语言）。`> [!note]-` 折叠成只剩标题，`> [!note]+` 展开，`> [!note]` 里的表格照样画成表格。自定义类型（`> [!我的类型]`）照画，用默认配色和笔记里写的那个词做标题。<br>**A callout such as `> [!note]` is drawn as a card.** Icon, title and body each take their place, the colour follows the type, and it is the same set Obsidian's reading view uses; with no title in the note the card shows Obsidian's own title for that type, in your interface language. `> [!note]-` folds it down to the title, `> [!note]+` opens it, and a table inside a callout is still a table. A custom type (`> [!my-type]`) is drawn too, in the default colour, titled with the word the note wrote.
- **`#标签` 画成徽章。** 只有行首、空格或左括号后面的 `#` 才算标签，所以 `C#`、网址里的 `#anchor` 和 `#42` 都还是普通文字 —— 和 Obsidian 自己的判断一致。<br>**A `#tag` is drawn as a badge.** Only a `#` that opens the line or follows a space or an opening bracket counts as a tag, so `C#`, a URL's `#anchor` and `#42` all stay ordinary text — the same rule Obsidian itself uses.
- **节点可以链接到别的笔记。** 右键菜单里多了「链接到某篇笔记…」「由该节点新建笔记」「打开链接的笔记」和「移除链接」，命令面板里也有对应的命令，都可以自己绑键。链接写进笔记就是普通的 `[[笔记名]]`，不是插件自己的格式，Obsidian 里照样能点。<br>**A node can link to another note.** The card's menu now carries **Link to a note…**, **New note from this node**, **Open the linked note** and **Remove the link**, with matching commands in the palette, all rebindable. What lands in the note is an ordinary `[[Note name]]` rather than a format of the plugin's own, so it still works in Obsidian.
- **新增「分支配色」设置。** **经典**是原来的那十种颜色，**跟随主题**改读 Obsidian 自己的 `--color-*`，让导图和界面其余部分同一个调子。两种配色都不写进笔记，导出的图里也照常带着颜色。<br>**A new "Branch palette" setting.** **Classic** is the ten colours the map has always used; **Follow the theme** reads Obsidian's own `--color-*` instead, so the map sits in the same key as the rest of the interface. Neither is written into the note, and an exported file carries the colours either way.
- **代码块卡片可以拖着搬走了。** 拖到另一张卡片上，它成为那张卡片的正文块；拖到一张卡片的上下边缘，它落到那张卡片旁边 —— 也就是成为那张卡片父节点的正文块；拖到另一张**代码块卡片**上，它落在那一块的上方或下方。搬动只改「把块挂到所属节点上」的那段缩进（两个节点正文列之差），块里的行一个字节都不动，所以围栏、代码、注释原样保留。段落和表格仍然不可拖动：那些行属于笔记，导图只是显示它们。<br>**A code block card can be dragged somewhere else.** Drop it on another card and it becomes that card's own body; on a card's top or bottom edge and it lands beside that card, as a block of that card's parent; on another code block card and it lands above or below that one. The move changes only the indentation that attaches a block to the node it hangs under — the difference between the two nodes' body columns — and touches not one byte inside the block, so fences, code and comments come through exactly as they were. Paragraphs and tables still cannot be dragged: those lines belong to the note, and the map is only showing them.
- **拖动选中的卡片时，整组一起走。** 选中好几张卡片后，拖动其中任意一张，整个选中都会跟着移动 —— 落在同一个位置，并保持它们在笔记里写的顺序，整个动作只算**一步撤销**。以前只有被抓住的那一张会动，而其余卡片上的选中圈一直在说它们也在这件事里。唯一的例外是正文卡片：代码块只有在你亲手拖它的时候才会被搬走，因为块是写在某张卡片下面的，它本身不是树里的卡片。<br>**Dragging one of several selected cards moves all of them.** With more than one card selected, dragging any of them takes the whole selection along — it lands together, in the order the note writes those cards in, and the whole gesture is **one undo step**. Only the card under the pointer used to move, while the rings on the others said they were in it too. One exception: a note-content card travels only when it is the card you picked up, because a block is written under a card rather than being a card in the tree.

### 修复 / Fixed

- **按住 `Ctrl`/`Cmd`+`Z` 不会再刷出一整列「没有可撤销的操作」了。** 撤销栈空的时候每按一次就弹一条提示，而一条要挂好几秒，所以按住不放的那一秒里就堆了十几条一模一样的句子。现在一段连按（按住不放，或者连着敲）**最多挂出三条**：随着按键一条条出现，松开之后一起消失；切走笔记或关掉标签页时也一起收掉。三条是有意的 —— 一条在角落里太容易被忽略，而这条提示正是按键还在起作用的唯一迹象。<br>**Holding `Ctrl`/`Cmd`+`Z` no longer fills the corner with "nothing to undo".** With the stack empty every press put up a notice of its own, and each one lives for seconds, so the first second of a held key piled a dozen copies of the same sentence. A run of presses — held down, or tapped in succession — now puts up **at most three**: they appear one per press until it has them, and they all go together a moment after you stop. Three is deliberate — a single notice in the corner is too easy to overlook, and it is the only sign the key is doing anything at all.
- **顶级分支可以拖到另一张顶级分支旁边了。** 落在顶级卡片上的「排到它前面 / 后面」以前会被拒绝，拖拽只好退回到唯一还合法的落点，于是不论往哪儿拖都变成「成为它的子节点」—— 既没法给顶级分支换位置，也没法把深处的卡片提到顶级这一层。现在顶级分支和别的卡片一样：落在它旁边就是排到它前面 / 后面。同一趟还修好了根节点**左侧**那些卡片落点半边颠倒的问题：布局把一棵子树整个画在父节点的同一侧，那些卡片的孩子画在左边，「成为子节点」却在右边判，两半的分工正好反了。<br>**A top-level branch can be dragged beside another one.** A drop on a top-level card used to be refused for "before / after", so the drag fell back to the one slot that was still legal and every gesture became "become its child" — a top-level branch could not be moved and a buried card could not be brought up to that level. A top-level branch is now like any other card: beside it means before it or after it. The same pass fixed the two halves of every card **left of the root**, which were the wrong way round: the layout keeps a subtree on one side of its parent, so those cards draw their children to their left, while "become its child" was being read off their right half.
- 用中文、日文、韩文输入法打字时，那个用来确认候选词的回车不再被当成「保存」，编辑框不会在你打到一半时关掉。三处就地编辑（节点标题、正文卡片、注解条）都补上了组合态判断 —— 查找栏一直有这道判断，编辑框漏了。<br>Under a Chinese, Japanese or Korean input method, the Enter that confirms a candidate is no longer read as "save", so the field does not close mid-word. All three in-place editors (the node title, a content card, an annotation) now carry the composition guard the find bar has always had.

### 改动 / Changed

- **`Space` 折叠改成「松开」时生效。** 展开 / 折叠原来是按下就触发，可同一个键现在还要当平移键 —— 按住它拖画布的同时把卡片折起来，显然不是谁想要的。所以它照旧按下，但等到**松开**才动作：这中间只要按过鼠标左键（也就是那一下其实是平移），这一次就不折叠。把折叠改绑到别的键上的用户不受影响，仍然是按下即触发。<br>**`Space` folds on release.** The fold used to fire on the way down, and the same key is the pan key now — folding a card while dragging the canvas with it is plainly not what anyone meant. It still goes down like any other key, but nothing happens until it comes **back up**: a press of the mouse in between (which is to say, a pan) drops the fold for that hold. A fold moved to another key is untouched, and still fires on the way down.
- **顶级分支的先后顺序现在由你的笔记决定。** 布局从来只是*读*笔记里写的顺序 —— 先读根右边那一列，再读左边那一列 —— 再按子树重量把它切成两半分到两侧，所以这个顺序一直是可以改的，以前只是不允许改。现在 `Ctrl`/`Cmd`+`↑`/`↓` 和在导图上拖都能给顶级分支换位置；**均衡模式下把一张拖过分界点，它会换到根的另一侧**，因为顺序是第一位的、边跟着顺序走。想让位置和顺序完全对应，把「布局」设成**单侧**。落点跟着卡片所在的侧镜像：背对根节点的那一半是「成为子节点」，朝向根节点的那一半是「排前 / 排后」。<br>**The order of the top-level branches is your note's to decide now.** The layout only ever *read* the order the note is written in — down the right column of the root, then down the left — and cut that order in half by subtree weight, so the order was always changeable; it was simply not allowed. `Ctrl`/`Cmd`+`↑`/`↓` and dragging both move a top-level branch now, and **in balanced layout a drop past the halfway point moves it to the other side of the root**, because the order comes first and the side follows it. To have position and order line up exactly, set **Layout** to **One side**. The two halves of a card mirror with the side it is on: the half facing away from the root is "become its child", and the half facing the root is "before / after".
- **注解条**里 `Enter` 现在是**换行**，保存改到了 `Ctrl`/`Cmd`+`Enter` —— 注解本来就可以有好几行，插件自己的提示文案一直也是这么写的，只是编辑器没照做。**代码块卡片**在编辑时用 `Shift`+`Enter` 另起一行，因为代码没有换行就不成其为代码；卡片只是被选中、没在编辑时，`Shift`+`Enter` 仍然是导图自己的「添加文字块」，和别的卡片一样。**节点标题、段落卡片和表格卡片**的 `Enter` 保存一律没动。<br>In an **annotation**, `Enter` now writes a line and saving moved to `Ctrl`/`Cmd`+`Enter` — an annotation may hold several lines, and the plugin's own hint text has always said so; the editor just did not do it. A **code block card** takes `Shift`+`Enter` for a new line while it is being edited, because a sample without its line breaks is not the sample; with the card merely selected and no editor open, `Shift`+`Enter` is still the map's own "add a text block", exactly as it is for every other card. A **node title, a paragraph and a table** all keep saving on `Enter`, unchanged.
- **新增「拖动模式」设置，空白处直接拖动的默认行为随之改变。** 关闭时（默认）在空白处直接拖动是**框选**，平移画布改为按住 `Space` 再拖（鼠标中键和滚动照旧）；打开后直接拖动就是平移，框选改用 `Shift` + 拖动 —— 也就是这个设置出现之前导图本来的样子。两种情况里 `Space` + 拖动和 `Shift` + 点击都照常有效，所以随时可以试。**第一次打开会弹一条说明**，因为它换掉的是你已经形成习惯的手势，不说一声就像导图坏了；之后再关再开都不再提示。设置在「设置 → MindFlow → 偏好」里。<br>**A new "Drag mode" setting, and with it a new default for what a plain drag on blank canvas does.** Off — the default — a plain drag on blank canvas draws the **selection box**, and the map is moved by holding `Space` and dragging (the middle button and the scroll wheel are unchanged); on, a plain drag moves the map and the box moves to `Shift`+drag, which is how the map behaved before the setting existed. `Space`+drag and `Shift`+click work either way, so it costs nothing to try. **Turning it on the first time puts up a notice**, because what it moves is a gesture you already have in your fingers, and moving one silently feels like the map broke; turning it off and on again says nothing. It lives in Settings → MindFlow → Preferences.
- 就地编辑时按 `Tab` 不再把焦点扔给界面上「下一个」元素 —— 那会顺带通过失焦把编辑提交掉，而焦点落在哪儿你完全没得选。现在它明确地保存并结束编辑，焦点交回导图。<br>Pressing `Tab` while editing no longer throws the focus onto whatever element comes next in the interface, which closed the editor through the blur on the way past and left the focus somewhere you never picked. It now saves and ends the edit outright, and hands the focus back to the map.
- **新增两个键位和两个手势**，都在快捷键设置里，可以改也可以清空：`Ctrl`/`Cmd`+`H` 查找替换（默认绑定），`Shift`+点卡片加选、`Shift`+拖拽空白处框选。按住 `Shift` 时空白画布**不再平移**，因为那个手势现在是框选；不按 `Shift` 平移照旧。<br>**Two new keys and two new gestures**, all in the shortcuts settings, all rebindable and all clearable: `Ctrl`/`Cmd`+`H` for find and replace (bound by default), `Shift`+click a card to add it to the selection, and `Shift`+drag on blank canvas to band a selection. Blank canvas **no longer pans** while `Shift` is held, because that gesture is the band now; without `Shift` it pans exactly as before.

## [2.0.0] - 2026-09-16

MindFlow 的第一个版本。<br>The first release of MindFlow.

### 新增 / Added

- 是一种视图模式，不是导出：在同一个标签页里把任意笔记切换成可编辑的放射状思维导图，不生成、不复制任何文件。每一次修改都按最小的行级编辑写回原来那份 `.md`，你没有动过的行逐字节原样返回，CRLF 也一样；frontmatter、围栏代码块、表格、HTML 和链接永远不会被重新格式化。<br>A view mode, not an export: toggle any note into an editable radial mind map in the same tab, creating and copying nothing. Every edit goes back to the original `.md` as the smallest line-level change, and lines you never touched come back byte for byte, CRLF included — frontmatter, fenced code blocks, tables, HTML and links are never reformatted.
- 在画布上就地编辑：重命名、新建、删除、缩进、拖拽改父级、拖拽调同级顺序、折叠、勾选复选框，都在卡片上直接完成，不弹对话框；悬停在卡片上出现的加号可以从这张卡片直接长出新节点。同级也可以用 `Ctrl`/`Cmd`+`↑` / `↓` 从键盘换位，效果和把卡片拖到那个同级的边缘一样。<br>Edit on the canvas: rename, create, delete, indent, re-parent by dragging, reorder siblings by dragging, fold and tick a checkbox, all on the card and with no dialog in the way; the plus that appears on hover grows a child straight from that card. Siblings also swap from the keyboard with `Ctrl`/`Cmd`+`↑` / `↓`, exactly as if the card had been dragged onto that sibling's edge.
- 节点注解：标题或列表项下面写一行 `: text`，它贴在卡片下方以灰色文字和左侧竖线显示，而不是单独成卡。双击或右键菜单即可编辑，写回只替换注解自己的那几行；节点折叠时注解仍然可见，导出时也跟着它的卡片一起走。<br>Node annotations: a line written as `: text` under a heading or list item hangs under that card in muted text behind a vertical rule instead of becoming a card of its own. Double-click one, or use the context menu, to edit it, and the write replaces only the annotation's own lines. An annotation stays visible when its node is folded, and goes into the exports with its card.
- 正文卡片：段落、代码块和表格画在所属标题旁边，过长的内容按卡片宽度折行而不是撑破卡片；表格按表格画 —— 表头、列对齐、单元格里的行内标记都跟着来，而不是一段等宽文字；`Shift`+`Enter` 另加一段没有标题的文字块。<br>Body cards: paragraphs, code blocks and tables are drawn beside the heading they belong to, and long content wraps at the card's width rather than bursting it; a table is drawn as a table — header row, column alignment and the inline markup inside its cells — rather than as a run of monospace text; `Shift`+`Enter` adds a plain block of text with no heading of its own.
- 三种卡片样式（边框 / 圆角卡片 / 极简）、曲线或直角连线，角落工具栏可以停在四个位置，也可以在你选中卡片之前先藏起来。<br>Three card styles (outline, rounded card, minimal), curved or right-angled connectors, and a corner toolbar that docks in any of four places or stays hidden until you pick a card.
- 导图上的每个快捷键都能自己改：设置里的 Shortcuts 组逐条列出动作、它是干什么的、以及现在绑在哪个键上。Record 记下你按下的下一个键，× 清空这一行，改过的行多出一个箭头把默认键放回来；两个动作撞到同一个键时两行都会提示。改完立刻生效，已经打开的导图不用重开。<br>Every key the map answers to can be changed: a Shortcuts group lists each action, what it does and what it is on. Record takes the next key you press, × leaves the row unbound, a reset arrow appears on any row you changed to put its default back, and a clash is called out on both rows. A change takes effect immediately, with no open map to reopen.
- 设置是一个独立窗口，浮在导图之上 —— 调外观和结构时不用离开正在看的这张图。<br>Settings are a window over the map, so changing how it looks and behaves does not mean leaving the map you are working on.
- 一篇笔记一份撤销历史：Markdown 编辑器和导图共用同一个撤销栈，`Ctrl`/`Cmd`+`Z` 会一路回退过去。<br>One undo history per note: the markdown editor and the map share a single stack, so `Ctrl`/`Cmd`+`Z` walks back through both.
- 导图自带查找：`Ctrl`/`Cmd`+`F` 打开查找条，输入即搜，计数显示第几个 / 共几个，`Enter` / `Shift`+`Enter` 在命中之间来回跳，`.*` 切换成正则。匹配的是卡片上看到的文字而不是原始 Markdown，跳到折叠分支里的命中会自动展开，走过去之后折回。<br>The map can find things: `Ctrl`/`Cmd`+`F` opens a find bar that searches as you type, counts which match you are on, steps with `Enter` / `Shift`+`Enter` and switches to a regular expression with `.*`. It matches the text you see on the card rather than the raw markdown, and opens a folded branch to reach a match and folds it back as you move on.
- 导出为 Canvas、SVG、PNG 或 HTML：右下角面板、命令面板和标签页菜单三处入口，导出的就是眼前这张图，文件落在笔记旁边，不覆盖已有文件。<br>Export to Canvas, SVG, PNG or HTML: from the corner panel, the command palette or the tab's menu, writing out the map as you see it beside the note and never over an existing file.
- 回来时还是你离开时的样子：折叠形状和焦点按笔记记住，存在插件自己的数据里，从不写进你的 markdown；笔记改名、移动时状态跟着走，笔记删除时一并清掉。<br>A map opens the way you left it: the fold shape and the card you were on are remembered per note, in the plugin's own data rather than in your markdown, and they follow the note when it is renamed or moved.
- 界面中英双语，跟随 Obsidian 自己的语言设置。<br>The interface ships in Chinese and English, following Obsidian's own language setting.
- 大图不再卡：只有看得见的那一屏会被画出来，公式只排版一次，缩放停下来之后文字按你停住的倍率重画，所以放大了也清晰。<br>Large maps stay smooth: only the screenful you can actually see is drawn, each formula is typeset once, and text is repainted at the zoom you stopped on, so it stays crisp when you zoom in.
- 每份发布都带 `LICENSE`：GitHub release 的文件列表里有一份，手动安装出来的插件目录里也有一份。<br>Every release ships `LICENSE`: it sits among the release's files and inside a plugin folder installed by hand.
